# XXD Panel 007 原始プロンプト · 日本語訳

> 閲覧用の忠実な翻訳です。実行時の唯一の基準は[簡体字中国語の原文](zh-CN.md)です。

アップロードした各写真を、それぞれ1枚の独立したハイエンドなデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図を採用し、上下2つの領域の高さは厳密に1:1とし、それぞれ画面の50%を占めます。

上半分には元の写真を残し、被写体の構造、リアルな質感、自然な光と影、元の色彩の雰囲気を維持し、わずかにハイエンドな写真のカラーグレーディングのみを施して、雑誌写真やアート出版物のような質感を持たせます。画面比率に合わせるため、空、地面、または周囲の背景を自然に拡張できますが、被写体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別性の高い被写体、輪郭、姿勢、物語上の関係性を抽出し、気楽で親しみやすく爽やかな手書きの観察図譜として再構成します。広い真っ白な紙面を主な空間とし、テーマをいくつかの小さな実物風の図形、部分的なクローズアップ、小さな断面図、繰り返される小物、またはディテールの断片に分解し、画面の中上部と中央部にゆるやかに配置します。整然とした表にはせず、ずらした余白、おおむね横方向に読むリズム、手書きの短いフレーズで自然につなぎ、味覚、触感、音、動作、または記憶についての気ままな観察記録のように仕上げます。小さな図形にはテーマ固有の素材感、色、識別特徴を残し、小さなスケール、丸みを帯びた輪郭、わずかな遠近感、手描きで着色した痕跡を表現します。部分的に粒子、焦げた縁、くず、テクスチャ、または断面のディテールを加えます。標準的なアイコンに統一せず、絵本の挿絵と手帳ステッカーの中間にあるような実物メモの感覚にしてください。

文字は下半分の重要な骨格です。細い黒色で、ややあどけなさや手書き感のある短い単語、短文、擬音語、注釈を用い、図形の左右を縫うように配置します。一部は図形の縁に近づけ、一部は余白に浮かせ、字間をゆったりさせ、ベースラインをわずかに跳ねさせることで、「見ながら読む」親密な読書リズムを形成します。下部には、より小さな署名風の説明、番号、日付、タイトル、またはテーマを表す短いフレーズを1行加えることができ、文字が後から貼り付けた組版ラベルではなく、画面に自然に溶け込むようにします。

全体の配色は上の写真から抽出し、白い紙の余白が最大面積を占め、黒い細字が情報を担い、被写体の色は温かく、清潔で、やや高明度にします。少量の高彩度の暖色、暗色、またはテーマのアクセントカラーは、焦点、影、テクスチャ、リズムのアクセントにのみ使用します。スキャンした紙のわずかな柔らかさ、自然な圧縮感、不揃いな縁、絵具の吸収効果を残し、重い影、装飾的な枠、強い現代的な組版感は加えません。全体として手書きの観察ページ、絵本の情報ページ、アート出版物、気楽なエディトリアルデザインを参照し、爽やかで、優しく、素朴で、生き生きとし、読みやすく、生活感に富んだ視覚的な気質を表現し、テンプレート感、カートゥーン化、安っぽさ、過剰なデザイン感を避けます。
