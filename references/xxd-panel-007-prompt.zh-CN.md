# XXD Panel 007 · 手写生活观察图谱生成核心

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

严格把当前选定的一张照片作为唯一内容来源。不要借用样张、其他照片或历史成品的物件、观察项、构图、配色和文案。


## 0. 不可改变的美学动机

**当前照片中特定的主体或不可拆分关系 → 至少三个身份、材料、动作、功能或关系线索 → 拆解为若干实物状小图、局部特写、剖面小图、重复小件或细节片段 → 保留圆钝轮廓、轻微透视、源图颜色、材料纹理和手绘上色痕迹 → 松散分布在大面积洁白纸面的中上部与中段 → 以错位留白形成近似横向或符合目标文字方向的阅读节奏，不做表格 → 用细黑色手写短词、短句、拟声词和注释在图形左右穿插 → 以扫描纸张柔化、颜料吸收、边缘不齐和可选的小型底部署名行完成。**

亲密感来自对源图具体材料、触感暗示、重复方式、剖面、动作、声音线索或可见记忆载体的观察。不得虚构人物经历、地点、事件、所有权、情绪、记忆、味觉或声音；感官文字必须有视觉证据或用户上下文支持。若换一张无关照片后，片段选择、材料线索、手写观察和阅读顺序仍成立，成品失败。

## 1. 锁定源图与观察项

在内部判断但不输出分析：

1. 找出唯一主要主体或不可拆分关系，并锁定至少三个源图专属的身份、材料、动作、功能或关系线索。
2. 选择一个可辨认的整体或主片段，再选择真正有信息价值的局部特写、剖面、重复小件、碎片或细节；数量服从内容，不固定格数。
3. 为每个片段锁定源图中的轮廓、颜色、材质、开口、连接、层次、颗粒、焦边、碎屑、纤维、反光、接缝或纹理依据。
4. 规划中上部与中段的松散分布、错位留白和近似横向或符合目标文字方向的阅读顺序。
5. 锁定白纸、黑色细字、温暖清洁的主体色和少量高饱和暖色、深色或主题辅色的层级。
6. 如需文字，为每个有价值的片段准备有依据的短词、短句、拟声词或注释，并判断是否需要一行小型底部说明。

## 2. 实物状观察片段

- 每个小图都必须属于同一源图主体，像对同一事物的不同观察，而不是一套无关收藏物。
- 保留小尺幅、圆钝轮廓、轻微透视和手绘上色痕迹。整体、局部、剖面、重复或碎片之间要有尺度与功能差异。
- 粒子、焦边、碎屑、纹理、纤维、接缝、反光或剖面细节只有在源图支持时出现。
- 不把片段统一成相同大小、相同描边、相同角度的标准图标，也不使用通用贴纸、卡通脸或素材库物件。

## 3. 洁白纸面与松散阅读

- 洁白或轻微暖白纸面占最大面积。片段主要位于中上部与中段，保持充足错位间隔。
- 构图可近似横向阅读，但不能成为整齐行列、严整表格、卡片墙、栏目或居中的标本矩阵。
- 通过距离、留白、重复材料和手写短语自然串联。箭头或引线只在确有必要时少量使用，并保持手绘。
- 底部可有一行较小的署名式说明、编号、日期、标题或主题短句，但只有用户提供或可靠建立时使用，不能成为品牌条。

## 4. 手绘材料与颜色

- 小图保留源图自身的材料感、颜色和识别特征，采用温暖、清洁、略高明度的手绘上色。
- 白纸承担空间，黑色细字承担信息；少量高饱和暖色、深色或主题辅色只用于焦点、阴影、纹理和节奏。
- 保留扫描纸张的轻微柔化、自然压缩感、边缘不齐和颜料吸收，不做数字噪点滤镜。
- 禁止厚重投影、装饰边框、强烈现代排版、光滑矢量图标、塑料贴纸、摄影写实、复杂体积和 3D。

## 5. 007 专属文字系统

文字是图谱的骨架，让观众“边看边读”，不是后贴标签系统。

- 自动文案从可见材料、动作、功能、关系、可信感官暗示或已知上下文生成少量短词、短句、拟声词和注释；只为真正需要文字的片段写。
- 用户最终成稿逐字保留。地点、日期、编号、署名和记忆性陈述只有用户提供或可靠建立时使用。
- 使用细黑色、略带童稚或自然手写感的字形；字距松弛，基线轻微跳动，不同文字系统保持自然结构。
- 文字在图形左右穿插：部分贴近边缘，部分漂浮在空白中。保持呼吸，不遮挡关键材料线索。
- 禁止粗黑商业标题、严格无衬线标签、统一胶囊框、数据图例、伪外语和装饰性伪文字。

摄影面板中绝不出现文字。无字模式中，变化画框也不得出现字母、汉字、数字或伪文字。

## 6. 当前模式与壁纸

调用方会附上唯一当前模式、准确尺寸、源图可见性和锁定文字；只执行附加值。

- 每张壁纸按目标比例重新组织片段、留白与阅读顺序，系统 UI 区域保持低信息，不绘制 UI 或设备框。
- 连贯壁纸始终使用原照片＋同一张已批准定调图：原照片锁定身份和内容，定调图只锁定片段语法、松散阅读节奏、白纸平衡、手绘材料、色彩温度、扫描质感和手写注释行为。不得裁切或顺序垫图。

## 7. 生成前检查

1. 至少三个源图专属线索分布在观察片段中，所有片段都属于同一主体。
2. 整体、特写、剖面、重复或细节的选择有信息价值，没有固定格数和无关填充物。
3. 白纸占最大面积，片段松散分布于中上部与中段，形成可读节奏但不是表格、网格、卡片墙或图标集。
4. 小图保留圆钝轮廓、轻微透视、源图材料、颜色和手绘痕迹；细节有证据。
5. 黑色细字真正串联观看与阅读，短词、拟声词和注释准确、自然、符合目标语言。
6. 白纸、黑字、温暖清洁主体色和少量强调色层级清楚，并有扫描柔化、颜料吸收与边缘不齐。
7. 没有厚重投影、边框、强现代排版、通用贴纸、商业卡通、光滑矢量、摄影写实、3D、Logo、水印、UI 或样机。
8. 当前模式、尺寸、源图可见性、壁纸安全区与文字设置全部服从附加块。
